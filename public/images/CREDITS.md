| | |
| --- | --- |
| `storefront-glass.jpg` | **Real — the actual San Felipe branch.** Converted from the WebP in `/images` at the project root. |
| Everything else | Unsplash stock. Not Liters. |

The stock files are placeholders so the site is presentable before real
photography exists. Replacing any of them is a drag-and-drop: save your photo
over the same filename, and the site picks it up with no code change.

## Rejected during review

Three candidates were pulled and thrown out after looking at them:

- A cafe exterior with a legible **"N°15 COFFEE SHOP"** chalkboard and
  **"Le Petit Palace"** signage — another business's branding on the Liters site.
- A daytime shot of a lighting store, chosen for a slot that needed a night
  storefront.
- A bar with liquor shelving and a neon sign, for the hero background. Wrong
  read for a family cafe even behind the dimming scrim.

If you swap any of these yourself, check the same things: no other business's
name, no readable foreign signage, and the dish actually matches the label.
