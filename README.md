# Liters Cafe

Marketing + menu site for Liters Cafe, San Felipe Rd, Naga City. Built with
Next.js (App Router), React, TypeScript, and Tailwind CSS. Static site - no
database, no accounts, no payment processing. Ordering happens through a
pre-filled Facebook Messenger link.

## Stack

- Next.js 15 (Turbopack)
- React 19 / TypeScript
- Tailwind CSS 4
- Motion (animation)

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `pnpm dev` - dev server (Turbopack)
- `pnpm build` - production build
- `pnpm start` - run production build
- `pnpm lint` - lint
